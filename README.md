# Cryptobus

Source code of the **Cryptobus** website (cryp2bus.com).

Stack: React, Vite, Tailwind CSS.

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into dist/
npm run lint     # lint
```

Backend/API endpoints are configured through environment variables (see `.env.example` and the deploy workflow in `.github/workflows/`).
